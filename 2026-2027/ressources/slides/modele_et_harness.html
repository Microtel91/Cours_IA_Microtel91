La réponse au suspense

# Ce que le chatbot envoie au modèle AVANT ta question :
system : Nous sommes le mercredi 14 octobre 2026. Tu es un assistant
         gentil. Réponds en français. Tu peux chercher sur internet.
user   : Quelle est la date d'aujourd'hui ?
Ce programme autour du modèle s'appelle le harness (le harnais, l'équipement).
Le modèle ne connaît pas la date : il la lit.
La formule de l'année

L'intelligence ne vient pas que du modèle

Agent=🧠 Modèle+ 🔁 Boucle🛠️ Outils 📖 Contexte🚦 Permissions 🛑 Arrêt

Le modèle est le cerveau. Le harness est tout le reste.

Jeu de rôle

Le cerveau dans le bocal

🧠 Le Cerveau

Dos à la classe. Ne voit rien. Ne peut qu'écrire des demandes :
« OUTIL : lire la ligne 3 de refuge.csv »

🛡️ Le Harness

Seul à avoir le fichier et la calculatrice. Exécute les demandes autorisées, rapporte le résultat par écrit.

🙋 L'Humain

Pose la question.

La classe note chaque aller-retour au tableau : c'est la trace.

Trois manches

Même cerveau, équipement différent

Manche 1

Le cerveau seul.
Pas d'outil. Il doit répondre tout de suite.

Manche 2

+ un outil et une boucle.
Il peut demander… mais ne sait pas comment s'appelle le fichier.

Manche 3

+ du contexte.
On lui donne d'abord : nom du fichier, colonnes.

Les 5 pièces du harness

L'équipement autour du cerveau

🔁 Boucle

Essayer → regarder le résultat → recommencer.

🛠️ Outils

Les mains : calculer, chercher, lire un fichier, lancer du code.

📖 Contexte

Tout ce que le cerveau a sous les yeux, renvoyé à chaque fois.

🚦 Permissions

Ce qu'il peut faire seul, ce qu'il doit demander, ce qui est interdit.

🛑 Arrêt

Réponse trouvée · trop d'essais · l'humain dit stop.

Permissions

Le feu tricolore 🚦

Vert — il peut le faire seul : lire un fichier du projet.
Orange — il doit demander : modifier un fichier, envoyer un message.
Rouge — interdit : supprimer des fichiers, lire les mots de passe.
