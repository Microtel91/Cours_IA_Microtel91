# Mon Ikigai 🎯

*Ikigai* est un mot japonais qui veut dire « raison d'être » : ce qui donne envie de se lever le matin.
Un bon projet se trouve **au milieu** des 4 cercles.

Prénom : ______________________

```
              ❤️ CE QUE J'AIME
           ┌───────────────────┐
           │                   │
   ⭐ CE EN QUOI    🎯 MON     🌍 CE DONT LE
   JE SUIS DOUÉ   PROJET      MONDE A BESOIN
   (ou veux le     IDÉAL
   devenir)        │                   │
           └───────────────────┘
          🤝 CE QUI PEUT SERVIR À QUELQU'UN
```
