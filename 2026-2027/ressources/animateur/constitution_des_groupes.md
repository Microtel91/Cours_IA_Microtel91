# Constituer les groupes (S04)

Objectif : les élèves **choisissent** leur projet et leurs coéquipiers, sans que personne ne reste seul ni ne soit mis de côté.

## Méthode

1. **Marché des idées** (voir S04) → on garde N idées, N = nombre d'élèves ÷ 3 (arrondi). Fusionner les idées proches.
2. **Vœux secrets** — chaque élève écrit sur un papier plié :
   - vœu 1, vœu 2, vœu 3 (parmi les N projets) ;
   - **un** prénom avec qui il aimerait travailler (facultatif).
3. **L'animateur compose** les groupes pendant la pause, dans cet ordre de priorité :
   1. 3 ou 4 élèves par groupe (pas plus de 4 : au-delà, quelqu'un ne fait rien) ;
   2. chacun a l'un de ses 3 vœux de projet (viser le vœu 1 pour le plus grand nombre) ;
   3. chaque élève qui a donné un prénom est avec cette personne **si c'est réciproque**, ou au moins avec quelqu'un qu'il connaît ;
   4. si possible, mélanger âges et niveaux.
4. **Annonce** : groupes affichés, chaque groupe choisit un nom d'équipe.

## Cas particuliers

- **Un élève que personne n'a choisi** : le placer sur son vœu 1, à côté d'un élève bienveillant, et ne jamais le rendre visible.
- **Un projet qui n'attire que 1-2 élèves** : proposer une fusion avec un projet proche (souvent on peut garder les deux idées).
- **Deux meilleurs amis qui se dispersent ensemble** : les garder ensemble la première séance, observer, et redistribuer les rôles plutôt que les groupes.
- **Changement de groupe** : possible jusqu'à S06, plus après (sauf conflit grave).
