# S09 — L'IA peut se tromper

**À retenir** : une réponse sûre d'elle peut être fausse. Les 3 réflexes : **relire** (répond-elle à ma question ?), **recouper** (une autre source dit-elle pareil ?), **tester** (je lance le code, je refais le calcul).

## Notion (15 min)

1. Rejouer la démo avec un petit modèle : `python harness_refuge.py --niveau 2 --modele ministral-3b-latest`.
   Il répond souvent « Gribouille »… qui est déjà adopté. Qui l'aurait vu ? Comment ?
2. Montrer une image générée par IA, et demander : comment savoir si une image est vraie ? (La meilleure réponse : **vérifier d'où elle vient**.)
