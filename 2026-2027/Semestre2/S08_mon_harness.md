# S08 — Je construis mon harness

**À retenir** : le chat du club, ChatGPT ou Claude Code fonctionnent tous comme ça : un modèle, des consignes, des outils et une boucle.
Aujourd'hui, **c'est vous qui le construisez**.

**Préparer** : [S08_mon_harness.ipynb](../ressources/notebook/S08_mon_harness.ipynb) et `refuge.csv`, copiés dans le dossier de chaque binôme,
et une clé API par binôme (à révoquer après la séance).

## Déroulé (la séance entière, en binômes dans Jupyter)

L'un tape, l'autre lit les consignes, et on échange à chaque étape. Le code est donné : le but est de **comprendre chaque pièce**
et d'en **modifier** une, pas de tout écrire.

1. Le **modèle** seul.
2. Les **consignes** (« Tu es un pirate ») → la réponse change. C'est le contexte.
3. Un **outil** (exécuter du Python) → le modèle **demande**, il ne lance rien lui-même.
4. La **boucle** → il trouve la réponse du refuge tout seul.
5. La **permission** (« Autoriser ? o/n ») et l'**arrêt** (5 étapes maximum).

**Bonus** : améliorer la partie « Nos règles pour l'IA » de son `projet.md`. C'est le même principe que les consignes de l'étape 2.
