# S11 — Les agents qui codent

**À retenir** : un agent de code (Claude Code, Codex, opencode…) lit, écrit et teste du code tout seul, dans un harness.
Le travail de l'humain : **dire ce qu'il veut, fixer les règles, vérifier le résultat**. C'est ce que vous faites depuis le début de l'année.

## Notion (20 min, démo de l'animateur)

Dans un dossier de test, sur un petit jeu en Python :
1. **Prédire** : « Je vais lui demander d'ajouter un score. Que va-t-il faire en premier ? »
2. **Observer** : à chaque action, la classe nomme la pièce du harness (il lit un fichier → outil ; il demande la permission → permissions…).
3. **Vérifier** : on lance le jeu. Est-ce qu'il a fait ce qu'il dit ?
4. Montrer son fichier de règles (`AGENTS.md`) : « C'est la même chose que la partie "Nos règles pour l'IA" de votre `projet.md`. »

## Atelier

Format habituel. Objectif : à la fin de la séance, tout ce qu'on veut montrer en S14 fonctionne.
